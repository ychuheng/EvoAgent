# EvoAgent 源码讲解与学习手册

> 文档定位：本手册面向第一次接触 Agent 工程的学习者，用来解释 EvoAgent 已经实现的代码、模块之间的关系以及关键设计原因。后续每完成一个模块，都在本手册中继续追加对应章节。
>
> **建议先读[源码地图](../源码地图.md)**：它按主题给出章节范围和对应源码入口，比从第 1 章顺序读到第 109 章更快。全部文档的入口见[docs/README](../README.md)，当前能力状态见[当前状态](../当前状态.md)；本手册解释代码原理，不承担“现在到哪一步”的职责。
>
> 章节按开发顺序追加，同一主题可能分散在多个阶段（例如任务恢复同时出现在第 31～33、57～58、102～103、109 章），主题索引正是为此准备。

> **2026-09-27 已按主题拆分为四个分册。** 原 8177 行单文件按章节范围整体搬运，章节号与讲解内容未改写，只是各自独立成文件；本页保留为目录与总入口，历史上的相对链接仍然有效。
