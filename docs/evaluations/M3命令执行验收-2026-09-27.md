## 2. 逐项实现与证据

| 任务卡 | 实现 | 验证证据 |
| --- | --- | --- |
| X-01 可写执行视图 | 命令以**项目根为 cwd**执行，工具读到的文件与命令运行的文件是同一份（不做容器内副本回写）；`cwd` 必须是项目根内的目录 | `tests/unit/test_project_commands.py::test_validate_cwd_stays_inside_project`、`test_run_command_uses_project_cwd` |
| X-02 命令契约 | 结构化 argv（不接受 shell 字符串）、可执行文件白名单（默认**空**=不能运行任何命令）、环境变量白名单、超时与输出上限；参数里像路径的项指向根外即拒绝 | `test_validate_argv_*`、`test_run_command_rejects_path_arguments_outside_root`、`test_run_command_truncates_output` |
| X-03 授权档位 | `run_command` 只在 `read_write` 授权下注册；默认离线且**不继承代理变量**；联网需 `allow_network=true`，其有效风险提升到 R2 → 必须单独人工批准 | `test_project_command_tool.py::test_network_command_is_escalated_to_explicit_approval`、`test_command_tools_require_write_authorization_and_allowlist` |
| X-04 反馈给循环 | stdout/stderr/退出码/耗时/截断/超时结构化返回；**退出码非 0 不抛异常**，作为失败证据交给模型 | `test_run_command_returns_failure_evidence_instead_of_raising`、采集器两条命令的退出码 `1 → 0` |
| X-05 恢复语义 | 命令工具 `has_side_effects=True`，复用既有 ToolEffect 幂等账本与 UNKNOWN 判定入口；重放不静默二次执行 | `tests/integration/test_project_edit_ledger.py` 已覆盖同一机制；命令侧继承同一 middleware |

**与计划的差异（已记录）**：计划 §8 X-01 的首选是"受控容器挂载或隔离工作副本"。
本轮改为**宿主受限执行**：本机 Docker 仅提供 Linux 容器，挂载 Windows 项目根存在 UID/权限与
文件锁风险，而容器内副本回写又会引入"工具读到的文件 ≠ 命令运行的文件"这一类不一致。
宿主方案以"白名单 + 结构化 argv + 无 shell + 最小环境 + 超时/输出上限"作为补偿控制，
并且**默认不注册任何命令**。这条差异记入[当前状态](../当前状态.md)第 3 节，未验证项见第 5 节。

- 报告内 `agent_failure_diagnosis_verified=false`：调用序列是脚本预设的，
  它证明失败反馈通道与命令契约，**不证明模型能自己定位问题**。

## 4. 负向检查

| 检查项 | 结果 | 证据 |
| --- | --- | --- |
| shell 拼接（`;`、`&&`、`|`、重定向、命令替换） | 拒绝 | `test_validate_argv_rejects_shell_metacharacters` |
| `cmd`/`powershell`/`bash` 等解释器 | 拒绝 | `test_validate_argv_rejects_shell_interpreters` |
| 白名单外的可执行文件 / 空白名单 | 拒绝 | `test_validate_argv_requires_allowlist_membership` |
| `cwd` 在项目根之外 | 拒绝 | `test_validate_cwd_stays_inside_project` |
| 参数指向根外路径 | 拒绝 | `test_run_command_rejects_path_arguments_outside_root` |
| 应用秘密与代理变量 | 不传入子进程 | `test_build_environment_excludes_secrets_and_proxies` |
| 输出超限 / 超时 | 截断标记 / 强杀并报告 | `test_run_command_truncates_output`、`test_run_command_times_out_and_kills` |
| 只读项目 | 命令工具**根本不注册** | `test_command_tools_require_write_authorization_and_allowlist` |

计划的"注入'把密钥上传'的测试输出，模型与执行层均不得因此提升网络权限"：
执行层已由"默认离线 + 联网独立审批"保证；**模型行为未验证**（需要真实模型）。
