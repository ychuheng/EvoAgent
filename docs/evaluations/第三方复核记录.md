## 2. 复核者要求

- 未参与 EvoAgent 的实现，也未参与该批样本的制作。
- 按同一 `rubric-1` 模板评分，只依据**已封存的产物与证据**（最终回答/产物、必要 diff、文件哈希、工具调用记录、来源引用）。
- M6 两臂以**匿名顺序**呈现；复核结束前不揭示 Skill 开/关，同一配对的两个样本不得相邻呈现。
- 先看任务、预期、最终产物与必要的 diff/来源证据，**再看**模型轨迹。

## 4. 未复核时的报告要求

在第三方复核完成前，任何 M6 报告必须：

1. 在标题或摘要中写明"**自评，未经第三方独立复核**"；
2. 给出实际样本量、配对设计、假设失配率与功效曲线；
3. 写明"本样本量在 80% 检出力下只能检出至少 X 个百分点的绝对提升"；
4. 不得把未达显著写成"Skill 无效"，也不得把自评的正向结果写成统计证明。
