## 1. F-04 产物出口（已完成）

| 要求 | 实现 | 证据 |
| --- | --- | --- |
| 产物预览 | `GET /api/v1/artifacts/{id}` 返回元数据 + 文本预览；文本类（md/txt/json/csv/py/log/yaml/html/xml）默认预览，二进制不预览 | `test_artifact_preview_and_download_match_registered_hash` |
| 下载 | `GET /api/v1/artifacts/{id}/download` 按登记名下载，响应头 `Content-Disposition` 与 `X-Content-SHA256` | 同上（断言响应头哈希等于登记哈希、正文逐字节一致） |
| 哈希核对 | 导出前重算内容 SHA-256，与登记值不一致即 **409 拒绝导出**，不把被替换的内容当"可核对产物"发出 | `test_artifact_download_detects_tampered_content` |
| 来源 Task | 响应含 `run_id`，Trace 里也有 `artifacts` 列表（含 id/type/uri/hash/size） | `RunTrace.artifacts` + 页面"产物（F-04）"区块 |
| 链接权限与路径不越界 | 只读取**数据库里已登记的**产物（不接受任意路径），读取走 `LocalArtifactStore`（内部拒绝穿越） | `LocalArtifactStore._read` 的 `is_relative_to` 检查 |
| 大小上限 | `artifact_download_max_bytes`（默认 16 MiB）超过即 413，避免"下载"变成绕过上下文预算读任意文件的通道 | `test_artifact_download_refuses_oversized_and_unknown` |

页面侧：`TaskInspector` 增加产物区块，显示文件名、类型、字节数、登记 SHA-256 与下载链接；
预览长度下限 256 字节（更小的切片会把多字节字符切一半）。

## 2. F-02 文件入口（已完成）

| 要求 | 实现 | 证据 |
| --- | --- | --- |
| 冻结 Task 输入集 | `POST /api/v1/tasks` 的 `input_paths` 在创建时把每个文件的**内容哈希、字节数、类型标签**写进 `tasks.frozen_inputs`；该清单就是"Agent 读到了哪些文件" | `test_task_creation_freezes_inputs_and_records_event` |
| 任务中替换原文件不换输入 | 每次工具调用前复核输入集；哈希不符或文件不可用即抛 `input_changed`，运行以明确终态 `input_changed` 结束（不是悄悄换内容） | `test_freeze_and_verify_detects_replacement`、`projects/inputs.py::verify_inputs` |
| 不后台扫描目录 | 输入集只由用户提交的路径组成；没有授权项目时直接拒绝（409），Agent 不扫描项目之外的目录 | `test_input_paths_require_authorized_project` |
| 路径不越界 | 每个输入都走 `resolve_inside_root`，`..`、根外路径、符号链接一律拒绝 | `test_freeze_rejects_outside_and_missing` |
| 类型/大小可见 | 类型标签（text/document/image/binary）与字节数随 Task 返回；运行开始写 `input.frozen` 事件，页面显示实际输入 | `test_classify_labels_common_types`、`test_run_started_emits_frozen_input_list` |

**说明**：类型标签只做分类，**不做内容解析**——UTF-8 以外编码与 PDF 解析属 F-03，尚未实现。
因此 PDF 目前只是"被冻结并标注为 document 的输入"，Agent 还不能从中抽取文本。

## 4. 已知的相关缺陷（未修）

`sandbox/client.py` 的 Worker 侧响应体上限 8 MiB 小于 guest 产物 base64 后的体积（约 10.7 MiB）：
容器内产出的较大产物可能在 Worker 侧被判失败。这与本轮的产物**导出**上限是两件事
（前者是 `shell` 工具路径，后者是 HTTP 下载路径），仍记录在[当前状态](../当前状态.md) §3.1。
