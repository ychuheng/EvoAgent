> 本轮任务第 4 项：**再决定 M6 Skill 效果评测能否启动**。结论是**现在不能启动正式对照实验**，
> 但把能离线做完的准备全部做完了：dev 轨迹台账、候选 Skill、失配率换算工具、冻结路径与审查闸门。
> 本文给出逐项判定、已经就绪的东西，以及解锁所需的**确切**条件。
>
> 铁律：只用已核对的 dev/日常轨迹提炼；**绝不使用 M6/M7 holdout 轨迹**；没有实测失配率、
> 没有冻结预算与评审安排时，只能给探索性结论，**不得声称 Skill 有净收益**；
> 也不为了拿到正向结果反复消耗留出集。

## 1. 启动门槛逐项判定

计划 §11 要求按顺序满足：选定主要任务家族 → 从 dev 试跑实测失配率 → 用精确计算定 `N` →
准备 `N × K` 互不复用的 holdout → 冻结模型/评分/预算/评审安排。逐项现状：

| 门槛 | 现状 | 判定 |
| --- | --- | --- |
| 主要任务家族（唯一） | 预注册草稿选定 `code_comprehension`（[S-03 路径](M6冻结对照实验路径-2026-09-27.md)） | 草稿可用，但**未随实测失配率最终冻结** |
| dev 实测失配率 | **未测**：试跑额度已在 2026-09-28 用掉，用户要求停止付费调用；没有新的费用授权 | **阻断** |
| 计算所需配对数 `N` | 未定：`N` 必须由实测失配率推出（候选表见[预注册记录](M6预注册-2026-09-27.md)） | **阻断** |
| `N × K` holdout 库存 | 现有 **4 条**（1 train + 3 holdout），家族 `code_comprehension`；按候选失配率 10% 需要 78 条 | **阻断**（库存 4/78） |
| 模型与工具版本 | dev 试跑用 `deepseek-flash`，但**正式模型/工具版本未冻结** | **阻断** |
| 预算与价格假设 | 正式 scope 仍为空（M0c 闸门拒绝正式付费调用）；试跑额度已耗尽 | **阻断** |
| 评审安排 | 评审者**未指定**；预留比例（M6 1/3，≥20%）已记录 | 只能自评 → 结论上限为探索性 |
| 冻结对照机制 | 已实现并有测试（同模型/同工具/同预算、`seed` 固定两臂顺序、`N` 必须等于精确计算值、mock 证据不可声称） | **就绪** |

**判定：正式配对实验不启动**（holdout 库存不足 + 失配率未实测 + 预算未冻结）。
按计划的"holdout 用尽时暂停 M6 门槛判定"，当前应继续做 dev 调优或报探索性结果。

## 3. holdout 补样的成本口径（计划要求的独立成本项）

计划 §11 要求把样本制作与复核写成**独立排期与成本项**。已有可参照的实测：

| 批次 | 规模 | 本轮实际投入 |
| --- | --- | --- |
| `ledger-holdout`（M6 首批） | 9 个 fixture 文件 + 4 条样本（1 train + 3 holdout） | 原始 M0b 批次（本次未重做） |
| `beacon-holdout`（M7 扩充） | 新增 13 个 fixture 文件 + 28 条样本（24 正常 + 8 故障/越权） | 一个工作时段内完成：fixture 素材、锚点、验证器、台账、覆盖度与自查 |
| 折算单条 | 约 10 分钟量级（含锚点核对与台账登记） | **M6 的样本更贵**：同一家族内要能配对、两臂要能区分、每条都要有人工确认成功条件 |

因此按当前候选失配率 10% 的 `N = 78` 对估算，**M6 补样是一个需要单独排期的批次**
（数十条同家族可配对样本 + 人工抽查 + 预注册冻结），不能当作顺手任务；实测工时要在第一批
补样完成后回填本表（计划明确要求逐项记录，不得只记总数）。

## 4. 解锁顺序（按依赖排列）

1. **费用授权**：用户给出试跑额度（沿用 2026-09-28 的 5 元口径即可）与正式 scope 的额度/价格假设；
2. **测 dev 失配率**：在 dev 样本上跑 30 对配对试跑（control / treatment 两臂），把结果喂给
   `scripts/m6_dev_mismatch.py` → 得到实测失配率与 `N`；
3. **补 holdout 到 `N × K`**：新增同家族、可配对、与 dev/现有 holdout 独立的样本；登记进
   `manifest.json` 并通过 `check_sample_ledger.py`；
4. **冻结**：把 `N`、模型、工具版本、价格与预算、人评规则版本、第三方复核样本写进预注册并
   改 `status=frozen`；
5. **跑正式对照**：`scripts/m6_pair_experiment.py check → plan → analyze → record`；
   若样本仍不足，只报探索性结果（写明可检出效应）；
6. **人工发布/回滚审查**：按 [S-04](M6人工发布与回滚审查-2026-09-27.md) 出记录，自审必须标注。

## 5. 明确不声称的事

- **没有 Skill 效果结论**：一次正式配对实验都没跑；候选 Skill 未评测。
- **没有实测失配率**：任何"`N` 应该是多少"的说法都还是候选值推算，不是测量结果。
- **没有第三方复核**：复核者未指定，结论上限是带自评限制的探索性结果。
- **没有消耗 holdout**：`run_ledger.jsonl` 仍为空，M6/M7 样本一次都没正式用过。
