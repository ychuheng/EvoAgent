## 当前代码检查

- `frontend/src/pages/ChatPage.tsx` 使用持久化 Session/Task/Messages；`TaskInspector.tsx` 读取 `GET /tasks/{id}` 与 `GET /runs/{id}/trace`，不根据网页显示臆造模型/工具结果。
- `src/evoagent/runtime/persistent_runner.py` 在普通任务中按创建时冻结的 Session 截止点装入历史；Runtime Eval 固定样本历史单独处理。此行为已经有跨 Session 隔离集成测试。
- `src/evoagent/tasks/service.py` 的取消终态与 `src/evoagent/tools/approvals.py` 的人工决策共用数据库事实来源；本次修复取消后旧审批仍可操作的边界。
- `src/evoagent/core/loop.py` 在完整模型响应后冻结原始工具调用；Worker 重新领取任务时先从检查点执行这份调用，再向模型发送工具结果，避免模型重新生成不同参数而重复审批。它仍按原 ToolEffect 账本处理已提交或结果不确定的副作用，不根据相似文本复用许可。
- 默认 Mock Provider、浏览器固定响应测试和真实 DeepSeek 场景分别记录。浏览器测试证明交互/请求契约，不能证明模型质量；真实模型调用可能遇到服务网络失败，失败不从报告中剔除。

本轮补完代码的后端全量回归为 **414 passed、13 skipped**（配置专用 PostgreSQL/Redis 测试服务）；前端 TypeScript、12 项组件测试、8 项浏览器流程通过。13 个跳过仍为独立 Linux Docker 专项 11、SQLite 行锁路径 1、Windows 符号链接权限 1；本轮尚未重跑独立 Linux Docker 专项。浏览器流程使用固定 HTTP fixture，真实页面结果另列在上表。
