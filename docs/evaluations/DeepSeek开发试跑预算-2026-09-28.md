# DeepSeek 开发试跑预算（2026-09-28）

用户为本轮 **dev 试跑**给出的费用上限为 **5 元人民币**。本轮只使用已标为 `dev` 的项目样本；试跑结果不能进入 M6/M7 holdout 结论。

| 项 | 本轮值 |
| --- | --- |
| 模型 | `deepseek-flash` |
| 试跑上限 | 5,000,000 微元（5 元） |
| 单 Task 上限 | 1,000,000 微元（1 元） |
| 停止阈值 | 上限的 95%，为单次请求留出余量 |
| 输入单价假设 | 2 元 / 百万 token（高峰、缓存未命中） |
| 输出单价假设 | 8 元 / 百万 token（高峰） |
| 请求输出上限 | 2,048 token |
| Agent 总 token 上限 | 128,000 token / Task（16,000 与 64,000 均在 M3 dev 轨迹触发累计上限，已调大；单 Task 仍受 1 元费用闸门限制） |
| 上下文窗口配置 | 131,072 token（旧本地配置 32,768 在成功复测后阻止了最终答复；官方当前模型规格为 1M，本轮取更保守值） |
| 最大迭代 | 20（开发试跑） |

单价按 [DeepSeek 官方中文价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 2026-09-28 所列 `deepseek-flash` **高峰价**计，即使实际处于空闲时段或发生缓存命中，也先按较高价记账。上述数值写入本机忽略版本控制的 `.env.personal`；API Key 和原始私有正文不写入本报告。实际消耗须在试跑后从 `/api/v1/budget-status` 与 SpendRecord 核对。

这不是 M0c 正式预算：M6 的配对数与 M7 的任务量尚未据实测成本预注册，正式 scope 仍关闭。

截至停止试跑时，账本累计 **859,370 micros（约 0.859 元）**，低于用户授权的 5 元。失败和取消的尝试均计入该数值；用户要求尽快结束后没有再发起付费模型调用。详见[真实模型开发试跑记录](真实模型开发试跑-2026-09-28.md)。
