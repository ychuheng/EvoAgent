# 逐结论引用核对表（模板，2026-09-28）

> 用途：把[公开资料调研](公开资料调研评测方案-2026-09-27.md)的四个冻结样本，从"引用过来源"
> 推进到"**每条结论的引用是否真的读过正文**"，并给人工事实核对留出可填的位置。
>
> 机械部分由 `evoagent.evals.citations`（脚本：`scripts/check_answer_citations.py`）完成；
> **它不判断网页内容是否支持结论**，因此本表最后的"人工判定"列必须由人填写。
>
> 当前状态：**四个样本都还没跑过真实模型**（需要费用授权），所以下表是空模板，
> 不是结果。跑完后请把每个样本的实际结论逐行填进来。

## 1. 机械判定规则

| 判定 | 含义 | 是否算通过机械门槛 |
| --- | --- | --- |
| `backed_by_read_text` | 该结论至少引用了一个**读过正文**的来源（`fetched_text`） | 是 |
| `cited_without_reading` | 只引用了搜索摘要（`search_snippet`），没有读过正文 | 否 |
| `uncited` | 没有任何引用 | 否 |
| `unknown_source` | 引用的 URL 在本次运行的检索/读取记录里找不到 | 否 |

拆句规则：列表项（`-`/`*`/`1.`）各算一条；普通段落按 `。！？；` 与句号切句；
少于 6 个字符且无引用的片段丢弃。**嵌套列表项同样按结论处理**（保守：宁可多标一条）。

命令：

```powershell
# 对已保存的 RunTrace 逐结论核对（离线，可用 --json/--markdown 落盘）
.\.venv\Scripts\python.exe scripts/check_answer_citations.py --trace output/run-trace.json `
    --json output/citations.json --markdown output/citations.md
```

`personal_research_eval.py` 已把这一步并入自动检查（`conclusions_backed_by_read_text`）与
报告字段（`per_conclusion`）。

## 3. 记录要求

1. 每条结论填入**原文摘录**（不是改写），并逐条给出引用 URL 与级别；
2. 机械判定由脚本输出，不要手工改；
3. 人工判定只写"支持 / 部分支持 / 不支持 / 无法判断"，并在备注里写依据（页面小节或原文片段）；
4. 发现"引用与结论不符"的样本要**原样保留**，作为失败证据，不要重跑覆盖；
5. 人评完成后，把结论与限制写进带日期的评测报告，并注明评审者是实现者（自评）还是第三方。
