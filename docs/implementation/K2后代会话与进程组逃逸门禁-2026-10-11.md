# K2 后代会话与进程组逃逸门禁

Linux command_runner 在 exec argv 前始终安装继承式 seccomp：setsid、setpgid、unshare、setns 返回 EPERM，网络开放也不跳过。宿主先建立所控进程组，后代不能再主动换会话/进程组；double-fork 保留该身份。offline 另加原网络限制，allow_network=true 只放行网络，不放行进程逃逸。libseccomp 缺失或规则安装失败不启动 argv。

冻结树 08d08b726a4657881bd8daa8827e56ee823c7ead：隔离 Linux/Python3.13 定向 44 passed / 3 Windows-only skips，5.59 秒；512 文件 Ruff/格式检查通过。真实 fork 出来的后代分别尝试 setsid/setpgid，offline 与联网两条路径均被 EPERM 拒绝；原网络开关、项目命令和 /proc 可观测性用例保持通过。

配额脚本文案移除不存在的 RLIMIT_NPROC 保证，并把普通四子进程案例改成只由父进程 fork 四次，避免列表推导让所有后代继续 fork。该脚本本批没有整体重跑，不把文案修改当成硬配额证据。

本批没有实现单命令内核 pids/cgroup 硬配额；50ms /proc 软监控仍可短暂超额，也不计线程总数。Windows 可信本机路径不获得 Linux seccomp 保证。需要新会话的命令将失败，这是限制合同，不能绕过过滤器重试。本提交完整 exact-SHA CI 待核对。
