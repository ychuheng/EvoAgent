# P3 受控验证副本基础（2026-10-10）

`learning/replicas.py` 仅从主机代码注册的不可变小型 UTF-8 fixture 创建副本，客户端只能引用登记 ID。没有调用目录扫描、复制用户项目或原地恢复用户文件的入口。

- 单 fixture 最多 16 文件、256 KiB；拒绝敏感内容、二进制、绝对路径、父级路径、隐藏目录、Windows 设备名/尾点、大小写冲突与文件/目录冲突。
- 对照/候选/重复次数使用独立目录；原输入哈希与 manifest 冻结，重试只核对，不重写。残缺 manifest、内容改变、符号链接/junction、越界拒绝。
- 默认不开放任何执行命令、项目授权、模型调用或试用；本类只是副本准备阶段，后续由验证服务在短事务登记受控项目/任务权限与独立输入身份。

副本单元测试 16 passed；新增判据保护（完成/安全检查不能冒充业务成功，调研每项需用户核验事实支持）与输入契约合计 22 passed，原冻结 Linux 树 `2be8a83395bf89f6bab167f19bf1bdd845cfb0e7` 全量 1283 passed / 18 skipped；合并进程退出竞态修复后的树 `6ea06cde449690ca0e7633fe298f337a7a75cce9` 全量 1285 passed / 18 skipped（505.00s），Ruff check/format 443 files 通过。数据库接线仍未完成，推送后的完整远端 CI 待核对。文件 manifest/fixture_hash 是复现身份，不是“未参与提炼”的独立性证明；独立正例/反例判定还需要验证服务按来源输入内容和判据合同核对，不能用 fixture 名称变化证明独立。

此实现不声称防御拥有主机目录写权限的恶意进程在路径检查与创建之间实施文件系统竞争；部署仍须保证 replica 根为服务私有。发生创建途中中断时残缺目录不自动回写，后续专用清理可在核对独占身份后移除。
