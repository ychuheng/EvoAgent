# P3 真实验证与试用采用接线

宿主通过 personal_validation_real_enabled 显式登记唯一 host-real-v1 执行配置。客户端不能指定任意模型、endpoint 或凭据。默认旧 Mock 路径的请求体 hash 和策略身份保持不变；真实配置冻结 provider/model、endpoint 哈希、调用上限、超时与定价/数字预算。未批准额度、工作区额度为空/零、配置漂移会拒绝，所有调用先取得任务租约和来源检查，再在全局/工作区短事务中预留个人学习额度。普通任务计费与验证任务计费不重复；发送未知或已发送预留不能自动重发。

最多 6000 次冻结调用预算； reserved/settled/unknown 都占次数，released 才可重新预留。验证报告逐个绑定实际 EvalRun/Task/Run 与任务费用记录；全部比较组都有实际调用、用量已结算才可能获得资格。人工判定和试用准入再次比较数据库费用事实，不能以修改报告并重算 hash 冒充调用。独立正反例、实际选用和明确业务判定仍是额外必要条件。仅此接线不会改变正式发布指针。

前端显式加载登记配置、默认为 Mock，选择真实配置时说明计费。冻结正反例不会执行模型；开始验证必须另外操作。新增真实验证可用性字段由宿主登记与工作区模式/数字额度共同决定； trial_adoption_available 还受 personal_trial_enabled 控制，具体候选仍逐项审核。
