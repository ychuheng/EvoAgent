# P4 正式候选范围读取收口

## 本批行为

`skills/selection.py::FormalSkillReader` 是现有正式活动候选的共享读取入口：核对工作区/项目范围、Skill 状态/活动指针、版本状态、正文哈希、敏感内容、工具与风险、三态适用性。`retrieval/sources.load_source` 删除重复资格判断并委托它；BM25 入口使用同一读取逻辑。

默认工作区不代表全局授权。调用方有 scope_id 时先核对范围再读取正文；外部工作区候选即使哈希异常也不能污染当前任务。无调用方 scope 的内部索引读取仍沿原索引合同处理，并不授权注入。

范围以 Task 冻结 project_id 为准，不使用后来变更的会话项目。两个普通选择恢复路径重新核对 Skill 停用和范围；活动指针被新版本替代并不触发重新选择。BM25 首次领取候选按 Skill UUID 排序获取锁，资格复核与选择写入处于同一短事务。
