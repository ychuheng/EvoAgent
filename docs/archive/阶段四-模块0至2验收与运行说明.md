## 数据库升级

先停止旧版 Worker，防止不检查 epoch 的旧进程继续写入，再执行：

```powershell
.\.venv\Scripts\python -m pip install -e ".[dev]"
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\evoagent-worker
```

新迁移 `20260919_0005` 增加 `tasks.lease_epoch` 和 `runs.skill_selection_frozen`，已有数据分别初始化为 0 和 false；已有配置快照或选择记录仍会冻结历史检索结果。不要在运行中混用新旧 Worker。备份并确认无活跃任务后才考虑降级；回退命令为 `alembic downgrade 20260908_0004`，会删除新增字段。

旧 Run 的代码版本或上下文配置指纹与新 Runtime 不同，会以 `snapshot_incompatible` 失败，不静默采用新预算续跑。历史报告仍可读取；要继续旧语义，应使用对应旧版本的隔离运行环境，或新建任务。

## 上下文配置

| 环境变量 | 默认 | 含义 |
|---|---|---|
| `EVOAGENT_CONTEXT_POLICY` | `bounded` | 每轮检查；`legacy` 显式保留旧请求行为 |
| `EVOAGENT_CONTEXT_WINDOW_TOKENS` | 32768 | Mock 示例窗口；真实 Provider 必须显式核对配置 |
| `EVOAGENT_MAX_OUTPUT_TOKENS` | 4096 | 本轮输出预留，也是 Provider 实际输出上限 |
| `EVOAGENT_CONTEXT_SAFETY_MARGIN` | 1024 | 输入之外的安全余量 |
| `EVOAGENT_CONTEXT_STRICT` | false | true 时拒绝未验证计数方式；当前真实适配器会返回 `context_count_unverified` |
| `EVOAGENT_MAX_TOTAL_TOKENS` | 32000 | 原有 Run 累计消耗软预算，与窗口不同 |

必须满足窗口大于输出预留与余量之和。可选资料通过 ContextBuilder 的 `external_context` 显式标记；不会按用户文本中的“外部上下文”字样删除任务。数值较小的 priority 先裁剪；工具调用和对应结果完整保留。裁剪后仍超限时返回 `limit_reached/context_budget_exceeded`，没有调用模型。

显式兼容 CLI：

```powershell
$env:EVOAGENT_CONTEXT_POLICY = 'legacy'
.\.venv\Scripts\evoagent --demo
Remove-Item Env:EVOAGENT_CONTEXT_POLICY
```
