# P5 方法库只读整理建议

## 产品行为

Skill 页面选定一条方法后，可点击“查看整理建议”。查询该方法的确切工作区/项目范围，前端不自动请求、合并、弃用或创建学习请求。

新增 `skills/library.py::SkillLibrarySuggestions.inspect(scope)` 及 `GET /skills/library-suggestions`：同范围 enabled 方法，取最新版本并复查完整来源图；撤销、被隔离、无来源或不合格方法不参与整理。每次最多检查按 ID 排序前 20 条，额外读取第 21 条用于明确标注 truncated，不声称覆盖整个库。最新版本查询使用相关索引聚合，不先对整个库作版本分组。

文字相似度使用描述与步骤指令的词法 token Jaccard，排除名称、DSL 键及工具名；任一侧少于 5 个不同 token 不提供相似建议。两侧声明 applicability 须相同；正文 hash 相同给 identical_body，否则阈值 0.65 给 lexical_similarity。它不证明语义相同，也不是安全采用或自动删除的理由。返回冻结父版本 ID/hash/lock_version，实际人工合并仍重新读取、验证全部来源并要求确认。

创建至少 30 天且过去 30 天没有被冻结选择的同范围方法标记 low_usage，依靠已修正范围的持久选择记录查询。工作区级方法在项目内被选择也计使用；不把低使用等同无效、不删除或自动禁用。

前端类型/构建通过，Vitest **61 passed**；Playwright **16 passed（17.0 秒，Mock HTTP 响应）**；不把浏览器 Mock 回归说成真实后端部署验收。Windows 初始两项 2 passed / 1 skipped（PG 要求），最终以以上隔离冻结树为主要后端证据。未使用付费模型，不证明模型学习效果。

## 限制

相似算法为可解释线索，不作 embedding 或语义判断。首批只查看前 20 条，无全库分页遍历；大量方法库不输出全库整理完成结论。统计为选择使用记录，不保证步骤执行。完整远端五项 CI 尚待准确后继 SHA 核验；不把本地通过当成远端交付。
