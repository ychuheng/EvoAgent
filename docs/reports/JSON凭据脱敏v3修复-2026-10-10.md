# JSON 凭据脱敏 v3 修复

原始文本规则 v2 对带双引号 JSON 的 password、api_key、authorization、密码、密钥字符串漏检，结构化 redact_value 已脱敏而工具文本未脱敏。本批追加 quoted_json_credential 类别并将 POLICY_VERSION 升至 3；保留 JSON 键与引号结构，支持值内空格和转义引号，空字符串与已有占位符不重复改写。不是任意未知秘密识别器：未扩展单引号 Python 字典、转义键名或非字符串值。

扫描 worker 协议与同步检测共用 SENSITIVE_CATEGORIES，避免规则新增而类别白名单遗漏。工具结果携带 redacted 与类别标记。历史归档 verified/policy=2/hash 相同也不得复用旧检查：当前规则重新全量扫描，命中则隔离，事件只记录身份、哈希、规则类别，磁盘归档原文不改写。
