# P5 工作区方法使用范围统计修复

## 问题与行为

工作区级方法可以用于项目任务，但原统计和证据分页把 `project_id=None` 解释为“仅无项目任务”，因此遗漏实际采用记录，并使重复失败修订提示不可见。

`SkillUsageReports._selected` 与 `list_evidence` 统一范围语义：指定 workspace、未指定 project 时查询整个工作区；指定 project 时仅查询该项目。方法归属和工作区边界校验保留，不授予跨工作区读取权限，不使项目级方法成为工作区级方法。
