# P1 个人反馈与学习请求入口实施记录（2026-10-09）

本批次交付个人反馈、显式方法学习请求、工作区策略和冻结来源的控制面。它不等于完成 Skill 自进化：后台候选生成、验证、试用、选择和自动挂起分别仍属于 P2、P3/P4。默认 `EVOAGENT_LEARNING_ENABLED=false`，工作区学习策略默认 off；没有学习请求的普通任务不经过此流程。

## 实现与证据位置

- `learning/service.py`：反馈与请求/任务原子提交、客户端幂等别名、方法/事实/待澄清路由、乐观并发策略与取消/审查/拒绝/重试。候选确认仅完成审查，不修改 Skill active 指针或生命周期。
- `learning/repository.py`、迁移 `20261009_0024`：持久保存明确的学习授权。旧反馈不能证明有授权，迁移为 false，原正文 hash 和两个 revision 不重写；旧请求不能靠重放获得新授权，需用户明确新提交。
- `learning/sources.py`：personal 来源角色、评测链接、未知工具效果、权限版本和终态检查。来源仅收集有界结构化证据和引用，不读取原 artifact 正文；completed/helpful 分别是执行状态/用户陈述，不冒充业务验收成功。
- 独立脱敏来源正文通过当前注入检测与内容 hash 检查；冻结后不追读可变化原文件。读取前后复核来源有效性；敏感旧件隔离后不自动解除。来源撤销先持久禁用、取消在途学习身份，再排队清理。
- `learning/jobs.py`：维护 job owner/epoch/expiry、取消与 request lock_version 的双重 fence，为 P2 handler 提交建立契约。
- `api/routes/learning.py`：本地可信控制面反馈、请求、策略、操作和单件来源撤销，错误只返回稳定 code，不回显敏感输入。
- `frontend/src/pages/FeedbackPanel.tsx`、`LearningPage.tsx`：显式授权、任务/候选状态、取消/重试、只读候选、来源/费用证据与撤销。页面提示确认候选不会启用，不把排队显示成已学会。

## 兼容与边界

1. 原正式提炼路由保留响应与 Mock 兼容能力；学习开关关闭时拒绝调用。真实模型旧同步提炼暂时 fail-closed，错误 `legacy_paid_extraction_requires_learning_pipeline`，待 P2 接入统一学习费用预留后恢复安全入口，不能绕过子预算。
2. `learning_revoke` 已排队，P2 接线前尚无清理 handler；即时权限禁用已有实现，不能宣称此批次已完成磁盘擦除或 trial 自动挂起。
3. 自动发现入口不开放；当前仅显式方法请求。事实反馈不自动写 Memory，mixed/unsure 不自动调用模型。
4. 新来源文件若 DB 提交结果不确定则保留，不删除可能已持久引用的字节；尚未提交的本次临时文件可清理。孤儿文件对账须在后续维护补齐。
5. 真实模型、个人验证、trial 采用和收益没有在本批次运行；测试使用离线候选/Mock，不消耗付费模型额度。
