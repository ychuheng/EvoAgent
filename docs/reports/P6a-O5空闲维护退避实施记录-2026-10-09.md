# P6a O5：空闲维护退避与独立清理通道

本批实现独立开关 `runtime_maintenance_idle_backoff_enabled`，默认 false。只调整维护调度，不更改活动 Task 的租约、心跳、取消读取、fencing 或持久恢复点。O3 心跳合并另行实施，P6a 尚未整体完成。

## 实现与回退

`MaintenanceLane` 对低优先任务在空闲时采用 1→2→4→8 秒有界等待；有工作就立即检查下一项，收到入队提示后恢复一秒等待。`MaintenanceWorker` 的 all 模式保持原筛选，新增 critical（erase）和 background（archive/index）筛选。独立维护进程启用开关时运行两个通道，清理最多等待一秒，后台执行不会占用其协程。后续 learning handler/discover 调度尚未接入，不把此批写成已支持个人学习。

入队提示由 SQLAlchemy 外层事务提交事件发出，支持显式 commit 与 session.begin；savepoint 提交只合并提示，回滚不发布。通知只含 `scan`，不是持久任务或授权证据。每个 Wakeup 实例仅有一个合并发布协程，本地 Event 与 Redis 提示均允许合并；失败靠数据库兜底。API、执行 Worker、独立维护 Worker 及 Database.configured 的资源分别关闭，不遗留发布协程。

关闭开关保留原维护轮询及 QueueSession.commit 的同步发布路径。固定 `7610cd5` reference 对照覆盖 all 模式领取（到期、未到期、失联、重试耗尽）、Wakeup 发布/等待及活动任务取消调用序列。取消恰好提交在 heartbeat 和原独立查询之间时，reference/off/on 均立即读到取消并等待 Handler 停止后结清；不借八秒空闲退避控制活动心跳。

[空闲实测](P6a-O5空闲维护轮询测量-2026-10-09.json)：固定单通道真实等待各 60 秒，临时 SQLite，无模型。关闭为 60 次领取/60 SQL，开启为 10 次领取/10 SQL，均零提交；达到 ≤12 次目标。可用 `python scripts/benchmark_maintenance_polling.py --output output/maintenance-polling.json` 重跑。该结果不代表 PostgreSQL 事务数或总体任务速度。

[繁忙后台清理实测](P6a-O5繁忙后台清理响应测量-2026-10-09.json)：独立 PostgreSQL，后台真实领取后执行阻塞，清理通道按一秒兜底执行实际 Memory 擦除，刻意不发送任何入队通知。20 个不同等待相位，P95 966.011 ms / max 1072.768 ms，均擦除完成且后台仍阻塞。只覆盖无大体积派生产物的撤销 Memory，不能外推为任意物理擦除两秒完成。

## 取消测量：保留差异，不隐藏不利结果

[首轮取消测量](P6a-O5取消响应测量-2026-10-09.json) 为每任务独立临时 SQLite、30 个相位、顺序测 reference/off/on。Redis 未配置组 reference/on P95 9839.505/9702.451 ms；TCP 拒绝组为 9719.315/10579.691 ms。后者虽未超过 11 秒，但比基线慢 860.376 ms，不能据此宣称零退化。该组跨测量窗口及独立文件的差异进一步触发配对复测。

[同窗口 PostgreSQL 配对](P6a-O5同相位PostgreSQL取消测量-2026-10-09.json) 保留每个样本、heartbeat 等待和事务时间，正常/Redis TCP 拒绝各 30 对。预先领取任务以隔离恢复扫描，配对共享同一个 API 配置，仅对照活动 Worker reference 与 O5：

| 环境 | reference P95 / max ms | O5 P95 / max ms | 配对延迟差中位数 ms |
| --- | --- | --- | --- |
| Redis 未配置 | 10170.982 / 10511.628 | 10221.252 / 10471.276 | -3.022 |
| Redis TCP 拒绝 | 10078.244 / 10422.135 | 10076.833 / 10393.985 | -3.906 |

所有样本达到 11 秒绝对目标。配对差异正常为 -63.419～61.571 ms，断连为 -68.411～60.252 ms；未看到首轮那种一致约 0.86 秒的偏移。但正常组单个 P95 仍高 50.270 ms，因此不声称两个数字逐毫秒相等，也不将“无显著退化”冒充严格 P95 非退化验收。O5 默认关闭；P6a 最终放行还要结合 O3 的同相位/查询间隙测试及稳定环境测量，确认其取消合同。Handler 被取消表示本 fixture 停止派发，不等于远端模型/外部进程立即停止；外部清理另有既有验收。

全部离线、零付费调用，只使用临时库/目录，不操作生产服务。原始报告保留实际源码哈希；实验环境、版本窗口与限制不能省略。
