# 阶段二演示与故障注入

## 1. 一条命令启动

```powershell
docker compose up --build
```

Compose 会依次等待 PostgreSQL 健康、执行 Alembic migration，再启动 API 和单 Worker。API 只映射到本机 `127.0.0.1:8000`。

打开：

- OpenAPI：`http://127.0.0.1:8000/docs`
- Trace Viewer：`http://127.0.0.1:8000/viewer`
- Readiness：`http://127.0.0.1:8000/health/ready`

## 2. 离线可重复任务演示

先创建 Session：

```powershell
$session = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/sessions `
  -ContentType application/json -Body '{"title":"阶段二演示"}'
```

再提交 Task：

```powershell
$body = @{session_id=$session.id; goal="生成一份 Markdown 调研报告"} | ConvertTo-Json
$task = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/tasks `
  -ContentType application/json -Body $body
$task
```

默认 Mock Worker 不访问公网，会依次调用 Mock `web_search`、`file_write`，在当前 Run 目录生成 `report.md`，再给出确定性最终回答。使用下面命令查询状态、事件和 Trace：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/tasks/$($task.id)
curl.exe -N http://127.0.0.1:8000/api/v1/tasks/$($task.id)/events
Invoke-RestMethod http://127.0.0.1:8000/api/v1/runs/$($task.latest_run.id)/trace
```

配置真实 OpenAI-compatible Provider 与 Brave Search 后，同一 Worker 已注册 `web_search` 和 `file_write`，可以执行“搜索资料并在 Run Artifact 目录生成 Markdown 报告”。密钥只通过本地 `.env` 注入，不写入镜像、事件或文档。

## 3. 杀死 Worker 后恢复

提交会触发多轮工具调用的任务后，停止 Worker：

```powershell
docker compose stop worker
```

等待超过 `EVOAGENT_LEASE_SECONDS`，再启动：

```powershell
docker compose start worker
```

新 Worker 会先把过期运行转入 RECOVERING。存在合法 Snapshot 且没有不确定副作用时从 Snapshot 继续；执行中的副作用会变成 UNKNOWN，并创建人工确认，而不是自动重做。

## 4. UNKNOWN 副作用确认

在 Trace 中取得 approval ID 后：

- 确认外部动作没有提交，可以重试：请求体 `{"response":"retry"}`；
- 确认动作已经提交并提供结果：请求体 `{"response":"committed:<结果>"}`；
- 无法接受该动作：调用 reject。

```powershell
Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8000/api/v1/tool-approvals/<approval-id>/approve `
  -ContentType application/json -Body '{"response":"retry"}'
```

## 5. 故障矩阵

| 注入点 | 恢复证据 | 自动动作 |
|---|---|---|
| 模型请求前 | 无新 Snapshot、无 ToolEffect | 从上个快照重试 |
| 完整模型响应后、Snapshot 前 | 只有不完整尾部事件 | 从上个快照重试该轮 |
| ToolEffect PREPARED 后 | 未开始外部调用 | 经策略允许后可执行 |
| ToolEffect EXECUTING 后 | 结果无法由本库确认 | 转 UNKNOWN 并等待人工 |
| ToolEffect COMMITTED 后 | 有结果与哈希 | 复用结果，不再调用工具 |
| Run 终态事务前 | 租约最终提交尚未发生 | 进入恢复决策，不伪造终态 |

自动化证据位于 `tests/fault_injection/`、`tests/e2e/` 和 PostgreSQL CI 测试。阶段二不声称通用 exactly-once。

## 6. 清理

保留数据库和 Artifact：

```powershell
docker compose down
```

连同阶段二本地演示数据一起删除：

```powershell
docker compose down --volumes
```

执行带 `--volumes` 的命令会不可恢复地删除 Compose 命名卷，使用前应确认不需要其中数据。
