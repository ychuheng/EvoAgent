## 4. 下一步

按[个人通用 Agent 当前实现计划](EvoAgent-项目设计与分阶段实现计划.md)的工作包顺序推进；每项只在拿到真实证据后才移入第 2 节。

1. **工作包 B 收尾**：在个人模式入口配置真实 Brave Key，完成至少一条多来源调研任务与一份带可访问引用的报告；失败来源、空结果与服务故障分别留证（对应任务卡 B-03、B-04）。
2. **个人任务集**：为当前个人模式入口冻结一批用户任务、判分规则与最低门槛，在运行前提交，不与旧的 16 项混算（对应 F-01）。
3. **工作包 C**：先确定 Workspace ID 与物理文件根的映射，再实现受控上传/列表、产物预览下载与哈希核对（对应 C-01～C-05）。
4. **工作包 D**：用已提交事件驱动页面阶段展示，明确运行中消息的排队/取消语义，并把错误码转成可执行提示（对应 D-01～D-05）。
5. **发布演练**：干净卷安装、迁移、备份恢复与升级回滚演练，重新制作与当前镜像绑定的发布清单（对应 F-03、F-04）。
