# ADR-014：独立运行时实验与隔离评测

- 日期：2026-09-22
- 状态：接受；已取得 DeepSeek 小样本证据，完整效果验收仍独立进行
- 对应：阶段四模块 12

## 问题

Skill baseline 的含义是“不使用 Skill”。若把它同时解释为关闭记忆、关闭压缩或改检索后端，实验无法归因。公共工作区中的记忆、归档及索引也可能污染 HOLDOUT。

## 决定

新增 runtime_experiments 和 runtime_eval_runs，不复用 Skill EvalRun 的 mode。RuntimeExperimentSpec 明确声明唯一实验变量：context_policy、memory_mode、retrieval_backend 或 worker_count。control/treatment 必须恰好只有这一字段不同；模型、预算、检索参数、数据集 hash、代码版本及环境另行冻结。

每个 Case、repeat、arm 都建立独立 Workspace/Session。公开 history 以完整 Message 契约注入；公开固定 memory fixture 在同一创建事务中建立自己的来源。私有 Validator 只由采集器读取，不参与提示词、摘要或 Embedding。实验 Run 的派生消息不能被提取成记忆或归档；普通 Worker 不领取运行时实验任务，专用 Worker 按 experiment_id/arm 过滤。

实验 CLI 按 arm 启动指定数量的真实 Worker 进程，使用同一数据库、工具代码和共享资源限额；Task/Run 仍由现有租约状态机执行。报告复用 Validator 和 MetricsCollector，但保持独立结构。样本包括失败、未知 usage、实际配置 hash、检索降级、摘要估计和原始指标，输出均值、中位数以及完整样本。运行时配对另做声明变量归一化；不扩大 RunConfigSnapshot.comparable_with 的忽略范围。

主模型、摘要器、记忆生成器分别记账；本实现的 extractive-v1 不调用模型，实验禁止记忆自动生成，所以后两项为实际零调用。Embedding 单列。服务没有返回 usage 时总精确值为 null，已知小计仍保留。LoopState 增加可选 known_usage，使未知总量情况下的已知消耗也能跨 checkpoint 恢复。

## 边界

Mock Provider 用于证明系统链路，不证明回答质量或语义召回。mock-hash-v1 不冒充真实 Embedding。真实报告须提供模型配置、语料版本、资源环境，并与 Mock 报告分开保存。用户随后提供了 DeepSeek 密钥，已取得 6 对、12 次运行的小样本记忆实验；两臂均 5/6 通过，未证明成功率提升。本次交付仍不宣称阶段四整体效果验收完成。

MCP 故障、租约接管和执行容器使用已有协议/故障注入测试作为工程证据；没有把自然语言描述某个故障当作真的注入了故障。前端实验管理和阶段四最终交付矩阵仍属于后续模块。

## 验证

单变量拒绝测试、真实 Task 端到端、失败样本保留、来源禁止、独立 Workspace、报告幂等、unknown usage 分账、双进程调度与 PostgreSQL 迁移。入口及待办见[运行说明](阶段四-模块11至12验收与运行说明.md)。
