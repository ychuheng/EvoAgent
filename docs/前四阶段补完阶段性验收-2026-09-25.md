## 回归与尚未完成的门槛

本轮专用 PostgreSQL/Redis 后端全量 **415 passed、13 skipped**。13 项为独立 Linux Docker 专项 11、SQLite 上不适用的行锁语义 1、Windows 无符号链接权限 1；此前 Linux Docker 专项 11 项曾独立通过，本轮未重跑。前端 TypeScript 与构建通过，**12 项 Vitest、9 项 Playwright** 通过。浏览器固定 fixture 测试只验证页面契约，表中单列的 DeepSeek 任务才是实时模型证据。Ruff、Compose 配置及文档链接在交付前再次检查。

计划仍有未完成项：真实模型超时与无效工具参数的网页负路径、COMMITTED/UNKNOWN 副作用的网页联合操作、跨 Workspace/长上下文用户路径、多 Worker 故障与页面状态联合复验。现有集成及故障测试不能冒充这些用户路径。语义留出虽显示改善，只有 10 条同域短文本，且混合仍有一条失败；不能据此宣称普遍检索收益。正式 `v0.4` 发布门禁保持关闭，版本仍为 `0.4.0.dev0`。
