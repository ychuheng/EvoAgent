## 回归与尚未完成的门槛

本轮专用 PostgreSQL/Redis 后端全量 **417 passed、13 skipped**。13 项为独立 Linux Docker 专项 11、SQLite 上不适用的行锁语义 1、Windows 无符号链接权限 1；此前 Linux Docker 专项 11 项曾独立通过，本轮未重跑。前端 TypeScript 与构建通过，**12 项 Vitest、11 项 Playwright** 通过。浏览器固定 fixture 测试只验证页面契约，表中单列的 DeepSeek 任务才是实时模型证据。Ruff、Compose 配置及文档链接在交付前再次检查。

前四阶段的核心网页对话、真实工具调用、Skill 发布/禁用、记忆确认/撤销、MCP 审核/卸载和语义检索已有专项证据，但[补完计划](前四阶段补完与用户场景验收计划.md)要求的联合用户路径**尚未全部验收**。超时与无效参数的页面呈现只通过固定 Trace 测试；长上下文由后端策略测试覆盖，未从真实网页任务走通；进程崩溃测试是独立 SQLite 中单 Worker 退出后由替补进程恢复，尚未验证两个并行 Worker 下运行中崩溃与网页/数据库状态一致；Workspace 创建/选择入口通过浏览器模拟 API 测试，真实页面操作待复验。跨 Workspace 的真实 DeepSeek 任务通过，但最初由可信脚本建立隔离 Workspace。COMMITTED/UNKNOWN 的持久化恢复由子进程测试覆盖，页面 UNKNOWN 提示由固定 Trace 验证，两者尚未做同一真实部署的联合操作。

这些缺口是验收范围缺口，不据此否定对应实现。语义留出只有 10 条同域短文本，混合仍有一条失败，不能宣称普遍检索收益。正式 `v0.4` 发布门禁保持关闭，版本为 `0.4.0.dev0`。此前“前四阶段用户路径补完已完成”的结论超出了现有证据，本段予以更正。
