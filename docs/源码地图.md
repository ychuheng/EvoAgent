# EvoAgent 源码地图

本页回答“想理解一个行为，应先读哪些文件”。[四册源码手册](manual/00-总览与目录.md)负责解释因果链；这张地图负责定位当前仓库中的入口。路径表按**运行时数据流**排列，而非按阶段或创建日期排列。当前能力与验收缺口另见[当前状态](当前状态.md)。

## 1. 从用户的一句话追到结果

```text
frontend/ChatPage → api/routes/tasks.py → tasks/service.py → PostgreSQL Task/Run
      → workers/main.py 领取 Lease → workers/bootstrap.py 装配本 Run
      → runtime/persistent_runner.py → core/loop.py ↔ Provider / ToolExecutor
      → Trace、Artifact、Task 终态 → SSE / TaskInspector → 用户
```

从这条主线偏离时，先问偏离属于什么：项目授权与文件操作读第三册；崩溃/审批/恢复读第二册；记忆、Skill 与评测读第四册。第一次阅读先看[第一册](manual/01-系统全景与任务主线.md)，它把这些分支接回同一条 Task。

## 2. 按问题找源码入口

第三列供 `scripts/m1_dogfood_map.py` 用**只读项目工具**逐条检查，因此其中的路径都应在当前工作树中存在。文件路径相对 `src/evoagent/`，仓库根路径写全；目录以 `/` 结尾。

| 想弄懂什么 | 先读哪册 | 源码入口 | 核对重点 |
| --- | --- | --- | --- |
| 配置、Mock 与真实 Provider | 第一册 | `config.py`、`providers/base.py`、`providers/mock.py`、`providers/openai_compatible.py` | 配置冻结、流式模型响应与错误分类 |
| 内核数据形状 | 第一、二册 | `core/models.py`、`core/events.py`、`core/context.py` | Message、ToolCall、Run/LoopState 与事件语义 |
| 模型—工具循环 | 第一、二册 | `core/loop.py`、`core/runner.py`、`tools/executor.py`、`tools/registry.py` | 完整响应、工具调用、终止条件 |
| API 和会话入口 | 第一册 | `api/app.py`、`api/routes/tasks.py`、`api/routes/sessions.py`、`sessions/service.py` | 页面提交后哪一层创建事实 |
| Task/Run 与数据库 | 第一、二册 | `tasks/service.py`、`tasks/state_machine.py`、`db/models.py`、`db/unit_of_work.py` | 入队事务、消息截止点、合法状态转换 |
| 多 Worker 领取 | 第二册 | `tasks/lease.py`、`tasks/lease_guard.py`、`workers/main.py`、`workers/wakeup.py` | owner、epoch 与 Redis 的实际职责 |
| Run 装配和恢复 | 第一、二册 | `workers/bootstrap.py`、`runtime/persistent_runner.py`、`runtime/checkpoints.py`、`runtime/run_config.py` | Provider/工具绑定、配置哈希、快照兼容性 |
| 审批、副作用与重试 | 第二册 | `tools/policy.py`、`tools/approvals.py`、`tools/effects.py`、`runtime/recovery.py`、`runtime/retry.py` | UNKNOWN 与 COMMITTED 如何阻止重复动作 |
| 付费与配额 | 第二册 | `runtime/budget.py`、`workers/rate_limit.py` | trial/formal 账本、Redis 依赖错误 |

| 轻量 Trace 查看器 | 第一、二册 | `web/viewer.py` | API 外的只读展示入口怎样取已持久化事实 |
| 项目登记与撤销 | 第一、三册 | `projects/service.py`、`projects/schema.py`、`projects/boundaries.py`、`api/routes/projects.py` | Project 与 Workspace 区别、授权版本复查 |
| 目录发现和按需阅读 | 第三册 | `tools/builtin/list_dir.py`、`tools/builtin/find_files.py`、`tools/builtin/search_text.py`、`tools/builtin/project_file_read.py` | 路径/正文搜索、截断和来源路径 |
| 精确编辑与整理 | 第三册 | `projects/editing.py`、`projects/encoding.py`、`projects/organize.py`、`tools/builtin/project_edit.py` | 原哈希、行尾、每文件原子替换与回滚边界 |
| Linux 与 Windows 项目命令 | 第三册 | `projects/commands.py`、`projects/command_runner.py`、`tools/builtin/project_command.py`、`scripts/host_mode.py` | argv、cwd、审批与不同 OS 的隔离性质 |
| 独立 Shell 容器 | 第三册 | `sandbox/controller.py`、`sandbox/docker.py`、`sandbox/egress.py`、`tools/builtin/shell.py` | 与项目命令不同的执行路径 |
| 输入、PDF 和产物 | 第三册 | `projects/inputs.py`、`tools/builtin/project_extract.py`、`tools/builtin/file_write.py`、`trace/artifacts.py`、`api/routes/artifacts.py` | 输入冻结、文本型 PDF、哈希校验下载 |
| 公开网页与来源 | 第三、四册 | `tools/builtin/web_search.py`、`tools/builtin/web_fetch.py`、`trace/sources.py`、`evals/citations.py` | 搜索摘要、已读正文、引用是否有支持 |
| MCP 工具准入 | 第三册 | `mcp/service.py`、`mcp/discovery.py`、`mcp/adapter.py`、`mcp/bindings.py` | 发现、审核、激活、Run 冻结各自是什么 |
| 上下文预算与压缩 | 第二、四册 | `core/context_policy.py`、`core/context_budget.py`、`runtime/context_store.py` | 受保护消息、估算、恢复修订 |
| 记忆与归档 | 第四册 | `memory/service.py`、`memory/repository.py`、`memory/archival.py`、`memory/maintenance.py` | 来源原话、确认/撤销、作用域 |
| 派生向量与混合检索 | 第四册 | `retrieval/embeddings.py`、`retrieval/indexing.py`、`retrieval/hybrid.py`、`runtime/context_resolver.py` | Profile/代次、短事务、冻结选择 |
| Skill 定义、提炼与检索 | 第四册 | `skills/schema.py`、`skills/provenance.py`、`skills/extraction.py`、`skills/retrieval.py`、`skills/service.py` | 来源资格、DRAFT、活动版本和撤回 |
| 样本、配对与报告 | 第四册 | `evals/datasets.py`、`evals/coordinator.py`、`evals/metrics.py`、`evals/gates.py`、`skills/experiment.py` | 成功判据、可比性、成本与收益界限 |
| 最短命令行演示 | 第一册 | `cli.py`、`scripts/personal_preflight.py` | Mock 与真实部署别混淆 |

上表覆盖产品的主要包和对外脚本。某些包内文件未逐项列出，是因为它们只在具体问题下展开；反向扫描会检查是否有**整个顶层包**未被提及。运行 `python scripts/m1_dogfood_map.py` 可复核本表的路径存在性；它不调用真实模型，不能据此证明 Agent 自主理解仓库。

## 3. 按故障现象走最短路线

| 现象 | 先看事实 | 接着读 |
| --- | --- | --- |
| Task 长时间排队 | Task 状态、Worker Presence、Lease、Redis | 第二册第 2～3 节；[故障指南](运营故障指南.md) |
| 模型请求被拒 | Run 配置、预算状态、Provider 错误码 | 第二册第 4、6 节；`runtime/budget.py` |
| “已批准”却没执行 | Approval、ToolCall、ToolEffect 与租约 epoch | 第二册第 3～5 节 |
| 编辑后测试看到旧文件 | Project 根、容器挂载、cwd、实际 diff | 第三册第 2～4 节 |
| 页面产物列表为空 | 工具调用记录和 ArtifactRecord | 第三册第 5 节 |
| 选中了 Skill 但效果没提升 | 选择批次、任务成功判据、配对样本 | 第四册第 3～5 节 |
