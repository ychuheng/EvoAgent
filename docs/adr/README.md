## 什么时候写新 ADR

按[当前实现计划](../EvoAgent-项目设计与分阶段实现计划.md)第 15 节：某个工作包发现架构必须调整时，先记录问题、受影响的 Task/Run/数据、候选方案、安全和迁移影响，再更新计划与 ADR——不能在代码完成后倒写成“原计划如此”。编号顺延，不复用已删除的编号。
