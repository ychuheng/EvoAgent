# ADR-007：租约隔离与请求上下文预算

- 状态：已接受；PostgreSQL 并发验收等待具备服务的环境执行
- 日期：2026-09-19
- 范围：阶段四模块 0～2，`0.4.0.dev0`

## 背景

阶段二的 Worker 只把过期任务转为 RECOVERING，没有调用恢复决策。终态检查租约，但事件、快照和工具账本仍可能接收旧 Worker 的迟到结果。固定 Worker 标签也不能区分同名进程重启。阶段一的累计 Token 限制不能防止单轮消息和工具 Schema 超出模型窗口。

## 决策

1. 每轮 Worker 依次推进到期重试、回收过期租约、扫描 RECOVERING、领取任务。取消时等待 Handler 和心跳清理完成。持有者失去租约后停止当前执行，长轮询继续处理其他任务。
2. Worker owner 为可读标签加启动 UUID；Task 的 `lease_epoch` 每次领取递增，JobLease 携带 epoch。迁移 `20260919_0005` 给旧 Task 初始化 epoch=0。
3. LeaseGuard 在调用者写事务内按 Task → Run 顺序加锁，校验 owner、epoch、状态、Run 归属和有效期。PostgreSQL 使用 `clock_timestamp()`，SQLite 只提供功能测试用时钟。事件、快照、ToolCall/Approval/ToolEffect、Skill 选择、Run 配置、Artifact 元数据与终态均由运行入口注入同一租约保护。
4. Guard 和写入不能分成两个事务；不跨 Provider、工具或文件 I/O 持有 SQL 行锁。Artifact 写入前检查一次，登记元数据的事务再检查一次；失租前已开始的外部动作无法撤销，可能产生未登记文件。
5. 恢复检查全部 PREPARED、EXECUTING、UNKNOWN 效果并要求确认。过去的执行审批不代表未知结果已解决；再次崩溃要重新确认。多条待审批项全部处理后才能重新排队。COMMITTED 的结果继续按语义键复用。
6. `Run.skill_selection_frozen` 在选择记录及事件所在事务内保存，包含零命中；避免首次检索与配置保存之间崩溃导致重新选择。完整 RetrievalBatch 留给模块 7。
7. Settings 默认 `bounded`，每次 AgentLoop 请求先检查完整消息组及输入预算。保留 system、Skill、原始目标、工具 Schema 和全部工具调用/结果组；仅删除 ContextBuilder 标记的可选 user 资料。低 priority 先删，同 priority 按原始位置稳定排序。
8. 输入预算为 `context_window_tokens - max_output_tokens - context_safety_margin`，输出预留实际传给 Provider。无法容纳受保护内容时返回 `context_budget_exceeded`，不调用 Provider。过程写入 `context.checked/trimmed/rejected`，不把被裁剪资料正文写入事件。
9. MockCounter 的精确性只针对离线定义规则。真实兼容服务暂用 UTF-8 字节加封装余量，标记 `estimated`；`context_strict=true` 拒绝未经验证的计数方式。真实服务必须显式配置核对过的窗口，不把估算称为服务端保证。
10. Policy、计数器版本和预算进入 Loop/config 指纹。恢复配置不匹配返回 `snapshot_incompatible`，由 Worker 正常持久化失败。旧配置缺少 context_policy 时保留原 canonical hash；显式 legacy 保留旧请求行为，但不能用于伪装跨版本可兼容。

## 后果与验收

新增实际进程故障测试从 API 创建 Task，在只读快照、效果提交、外部动作后账本提交前分别杀死 Worker，再启动同标签进程。不由测试直接调用 RecoveryService。另有各写路径拒绝旧 epoch、审批聚合、零命中冻结、取消清理和请求预算测试。

PostgreSQL 行锁用例与 SQLite 功能用例明确分开，CI 的 PostgreSQL 17 服务会运行对应参数。本机未配置服务，不能声明已证明分布式并发正确。数据库 fencing 也不等于外部 exactly-once；Redis、容器沙箱、自动摘要、Memory、MCP、pgvector 均不属于本次交付。

升级必须停掉全部旧 Worker 后迁移 Schema，再启动同一版本 API/Worker。旧二进制不检查 epoch，不能与新二进制混跑。
